계획 문서 형식 (plan-format)

Claude(오케스트레이터)가 작성하고 실행자(Codex)가 소비하는 계획 파일의 형식. 위치는 대상 프로젝트의 docs/superpowers/plans/YYYY-MM-DD-<주제>.md (superpowers writing-plans 규약과 동일 — 계획 위치를 한 곳으로 통일한다).

형식

# <주제> 계획

## 태스크

- [ ] T1: <목표 한 문장>
  - 대상: <생성/수정할 파일 경로>
  - 배경: <실행자가 알아야 할 맥락 — 선택 사항>
  - 검증: `<실행 가능한 커맨드>` → <기대 결과>

- [ ] T2: ...

규칙

  1. 검증: 줄이 없는 태스크는 실행자에게 넘기지 않는다. 실행 가능한 커맨드와 기대 결과가 품질 게이트의 전부다.
  2. 태스크는 독립적으로 검증 가능한 최소 단위로 자른다.
  3. 체크박스(- [x]) 갱신은 검증 커맨드를 직접 실행한 오케스트레이터만 한다. 실행자는 체크박스를 건드리지 않는다.
  4. Linear 큐(Layer B)로 승격할 때는 태스크 1건 = 이슈 1건으로 옮기고, 검증: 줄을 이슈 본문에 반드시 포함한다.
