# 정민의 기술 포트폴리오

오픈소스 기반 교육용 소프트웨어를 제품 요구에 맞게 확장하고, 웹과 데스크톱 환경에 배포해 온 개발자입니다. JavaScript를 중심으로 Scratch 기반 애플리케이션, Node.js 웹 배포, Electron 패키징 작업을 경험했습니다.

## 다루는 기술

- **JavaScript / Scratch**: GUI, VM, Blocks, Desktop 모듈을 분석하고 제품 요구에 맞게 수정
- **React**: 기존 UI 구조를 파악하고 화면과 기능을 확장
- **Node.js / AWS**: 테스트용 웹 서비스의 빌드와 배포 환경 구성
- **Electron**: 데스크톱 패키지 배포와 빌드 과정 지원
- **Flutter / Dart**: 오프라인 데이터 기반의 한국어 낱말퍼즐 앱 개발
- **Unity / C#**: 에이전트 기반 Unity 개발을 위한 재사용 가능한 파이프라인 키트 설계
