# 중국향 Scratch 기반 교육용 애플리케이션

## 배경

오프라인 환경에서도 교육용 하드웨어를 사용할 수 있도록 Scratch 3.0 기반 애플리케이션을 중국 시장 요구에 맞게 확장하는 작업에 참여했습니다.

## 맡은 일

- Scratch의 GUI, VM, Blocks, Desktop 구조를 파악하고 요구 기능을 수정·추가
- 기존 React 및 JavaScript 코드 기반의 화면과 동작 흐름 개선
- 하드웨어 통신 관련 요청 사항의 수정 작업 지원
- Electron과 electron-builder를 이용한 데스크톱 패키지 배포 지원
- macOS 빌드 과정 및 배포 편의성 개선 작업 참여

## 사용 기술

JavaScript, React, Scratch GUI/VM/Blocks, Electron, electron-builder

## 공개 범위

상용 제품의 내부 코드와 고객별 요구사항은 공개하지 않습니다. 이 문서는 담당 영역과 기술적 경험만 설명합니다.
