# 국내 교육 제품 통합 및 기능 확장

## 배경

중국향 Scratch 기반 애플리케이션을 국내 교육용 제품군에 맞게 전환하고, 기존 소프트웨어 기능과 하드웨어 지원 범위를 통합하는 작업에 참여했습니다.

## 맡은 일

- 기존 교육용 애플리케이션의 기능 이전과 통합 작업
- STM 기반 제품의 컴파일·업로드 흐름 연동 작업 참여
- TensorFlow.js API 버전 업데이트와 이미지 분류 기능 추가
- 교육용 하드웨어와 소프트웨어가 함께 동작하는 환경의 기능 확장

## 사용 기술

JavaScript, Scratch 기반 모듈, TensorFlow.js, 하드웨어 통신·업로드 흐름

## 공개 범위

제품별 내부 구현, 교육 콘텐츠, 고객 정보는 공개하지 않습니다.
