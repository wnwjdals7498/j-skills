# Unity AI Development Pipeline Kit

## 목표

Unity 프로젝트를 코딩 에이전트와 함께 개발할 때, 구현뿐 아니라 비주얼 품질·위험도·검증 증거까지 관리할 수 있도록 만든 재사용 가능한 템플릿 키트입니다.

## 구현 포인트

- 비주얼 트랙과 코드 트랙을 분리한 단계형 파이프라인
- 요구사항, 영향 분석, 구현, 검증, 통합 검토를 연결하는 코드 작업 흐름
- 컨셉 분석, 블록아웃, 스크린샷 비교, 에셋 정책을 포함한 비주얼 작업 흐름
- Unity의 Scene, Prefab, SerializeField 등 위험 영역을 명시한 안전 규칙
- 상태 파일과 검증 증거를 사용한 작업 재개 구조

## 사용 기술

Unity, C#, PowerShell, Markdown 기반 작업 계약과 검증 문서

## 공개 범위

이 프로젝트는 재사용 가능한 개발 환경 템플릿이며, 특정 게임의 소스 코드나 에셋은 포함하지 않습니다.
