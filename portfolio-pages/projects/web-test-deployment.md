# Node.js와 AWS를 이용한 테스트 웹 배포

## 배경

데스크톱 중심의 JavaScript 애플리케이션을 브라우저에서도 확인할 수 있도록, 해외 접속을 고려한 임시 테스트 서비스를 구성했습니다.

## 맡은 일

- JavaScript 애플리케이션의 웹 배포 방식 검토 및 빌드
- Node.js 기반 실행 환경 구성
- AWS EC2 인스턴스와 외부 접속을 위한 네트워크 설정 지원
- 테스트 목적의 서비스 접근과 유지 절차 정리

## 사용 기술

JavaScript, Node.js, AWS EC2

## 배운 점

애플리케이션 기능 개발과 별개로, 사용자가 실제로 접근할 수 있는 배포 환경과 운영 조건을 함께 고려하는 경험을 쌓았습니다.
